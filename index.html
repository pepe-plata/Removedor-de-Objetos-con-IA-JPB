Ayuda

Uso en Android

  • Un dedo: pan o dibujar.
  • Dos dedos: pinch zoom + pan simultáneos.
  • Modelo IA: MIGAN (28 MB, optimizado para móvil).

Uso en Windows

  • Rueda: zoom. Shift+rueda: horizontal. Alt+rueda: vertical.
  • Espacio + arrastrar: pan.
  • Modelo IA: LAMA FP32 con WebGPU.

Atajos

  • Ctrl+O Abrir · Ctrl+S Guardar · Ctrl+C Copiar
  • Ctrl+Z Deshacer · Ctrl+Y Rehacer
  • + / - Zoom · 0 Ajustar · 1 100%
  • [ / ] Pincel

General

  • Procesamiento local, sin subir imágenes.
  • Modelos cacheados en IndexedDB.
  • Android: MIGAN · Windows: LAMA FP32.
